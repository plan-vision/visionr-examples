# VisionR Project Agent Guide

This file applies to the VisionR project rooted in this directory and its
subdirectories.

If the project is nested in a larger repository, also follow parent
`AGENTS.md` files; this file is the project-specific layer.

If `visionr.json` is not present yet, treat this directory as the intended
project root to generate into.

Before making changes, run commands from this root and resolve the installed
engine directory:

```console
vrs dir
```

Then read the shared project agent guide from the installed engine release:

```text
<engine-root-dir>/src/doc/project/project-agent-guide.md
```
